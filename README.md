# 🧠 Empathetic Mental Health Chatbot

An AI-powered mobile application designed to provide **empathetic mental health support through conversation**.  
The chatbot interacts with users in a compassionate and supportive way, helping them express their emotions in a safe environment.

The application is built using **Flutter** and powered by **Google's Gemini API** to generate intelligent and human-like responses.

---

## 🚀 Features

- **🤖 Real-time AI Chat**  
  Communicates naturally with users using Google Gemini AI.

- **💬 Empathetic Responses**  
  The chatbot is designed to behave like a caring mental health companion.

- **⚠️ Crisis Detection**  
  Detects sensitive keywords related to self-harm and provides helpful resources.

- **📱 Cross-Platform Support**  
  Built using Flutter, ensuring smooth performance on Android devices.

---

## 🛠 Tech Stack

| Technology | Purpose |
|-----------|---------|
| Flutter (Dart) | Mobile application development |
| Google Gemini API | AI conversation engine |
| Provider / setState | State management |
| Dio / HTTP | API communication |

## 📦 Installation

### 1. Clone the repository

```bash
git clone https://github.com/yourusername/empathetic-mental-health-chatbot.git
```

### 2. Navigate to project directory

```bash
cd empathetic-mental-health-chatbot
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Run the application

```bash
flutter run
```

---

## ⚙️ Configuration

Add your **Google Gemini API Key** in the configuration file.

Example:

```dart
const String apiKey = "YOUR_GEMINI_API_KEY";
```

## ⚠️ Disclaimer

This application is intended to provide **general emotional support only** and should not replace professional mental health services.  
If you are experiencing serious mental health concerns, please consult a qualified professional.
